# DCB テンプレート 10.24.3

Sekiban DCB 10.24.3 用の 5 つのスターターテンプレートです。生成されるプロジェクトは 10.24.3 のパッケージと Orleans 10.4.2 を参照します。このノートは、テンプレート 10.24.2 からの変更をまとめたものです。

## 含まれるライブラリの変更

- 10.24.3: 同じデータベースのマテリアライズドビューの初期化を 1 つずつ順に実行するようにし、2 つが同時に初期化してもホストが止まらなくなりました（[#1362](https://github.com/J-Tech-Japan/Sekiban/issues/1362)）。`InMemoryEventStore` は、イベントのないタグに空のタグ状態を返します（[#1340](https://github.com/J-Tech-Japan/Sekiban/issues/1340)）。PostgreSQL では、イベントのタグが 2 つ以上ある追記が、タグの数によらない一定数の一括 SQL でタグの head を更新します（[#1347](https://github.com/J-Tech-Japan/Sekiban/issues/1347)）。公開 API と依存パッケージは 10.24.2 から変わっていません。詳しくは 10.24.3 のライブラリのリリースノートを見てください。

## テンプレートの変更

- テンプレートは Sekiban DCB 10.24.3 を参照します。生成されるプロジェクトのそれ以外の部分は変わっていません。

## 既存のプロジェクト

テンプレートのパッケージを更新しても、すでに生成したプロジェクトは変わりません。ライブラリの変更を取り込むには、`SekibanDcbTemplateVersion.props` の `SekibanDcbVersion` を `10.24.3` にしてください。ほかの変更は要りません。
