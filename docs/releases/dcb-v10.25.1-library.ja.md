# Sekiban DCB 10.25.1

- バージョン: `10.25.1`。DCB ライブラリは 26 パッケージです。10.25.0 と同じく net10.0 と net11.0 を対象とします。
- 10.x 系のパッチリリースです。10.x 系は今後、緊急のパッチだけを出します。Unsafe Window マテリアライズドビュー、DynamoDB のチェックポイント書き込み、イベント配信統計の不具合を修正しました。公開 API と依存パッケージは 10.25.0 から変わっていません。Orleans は 10.4.2 のままです。
- DCB のイベントデータの移行は不要です。

## 修正

- **Unsafe Window マテリアライズドビュー: null 許容列の null 値。** 4 つのプロバイダー（PostgreSQL、SQL Server、MySQL、SQLite）すべてで、null 許容列が null の行の書き込みが失敗していました。値を `DBNull` として Dapper に渡しており、Dapper がこれを受け付けないためです。ワーカーは再試行のたびに失敗し、ビューはそのイベントで止まったままになり（再起動後も同じ）、以降のイベントは反映されませんでした。null 値は null として書き込むようになりました。
- **SQL Server: 型付きパラメーター。** `VARBINARY`、`BINARY`、`IMAGE` 列への null は、型付きのバイナリの null としてバインドします（型なしの null は SQL Server がエラー 257 で拒否します）。`DateTime` の値は、列が日付・時刻型のときに `DATETIME2` としてバインドします。これまでは `DATETIME` としてバインドしていたため、1753 年より前の日付を `DATE`、`DATETIME2`、`DATETIMEOFFSET` 列に書くと失敗して同じようにワーカーが止まり、約 3 ms より細かい精度は丸められていました。どちらも保たれるようになりました。それ以外の列のバインドは変わりません。`DATETIME2`、`DATETIMEOFFSET`、`TIME` 列にすでに書き込まれた行は、ビューを再構築するまで以前の約 3 ms の丸めのままです。
- **PostgreSQL と SQL Server: safe から unsafe への修復コピー。** safe テーブルから unsafe テーブルへのコピーをデータベース内（`INSERT ... SELECT`）で行うようになり、`JSONB` や `DATE` などの値は型を保ったままコピーされます。これまでは .NET を経由していたため、コピーが失敗することがありました（PostgreSQL では `JSONB` のエラー 42804 や `DATE` 列、SQL Server では 1753 年より前の日付など）。
- **DynamoDB のチェックポイントストア。** 条件付きのチェックポイントの更新（最初の 1 回を除く）と、再構築したチェックポイントの確定が、すべて失敗していました（tombstone の書き込みは影響を受けていません）。リクエストに使っていない式属性名（`#u`）が含まれており、DynamoDB がこれを拒否するためです。それでも永続化は成功を返していたため、保存されたスナップショットは最初のもののまま進まず、再構築したスナップショットは確定されず、再構築の義務は未完了のまま残っていました。条件付き書き込みは、使う名前だけを送るようになりました。
- **イベント配信統計。** 以前の内部リファクタリング以降、`RecordingMultiProjectionEventStatistics` にイベントが一切届かなくなっており、`GetEventDeliveryStatisticsAsync`（とテンプレートの `*/event-statistics` ルート）は常に 0 を返していました。記録を戻しました。Orleans のストリームから届いたときと、キャッチアップ（`AddEventsAsync` を含む）で取得したときに、重複除去やフィルターの前に数えます。組み込みの実装はスレッドセーフです。既定の `NoOpMultiProjectionEventStatistics` では、これまでどおり何も記録せず、メモリも確保しません。記録する実装は配信されたイベント ID をすべてメモリに保持するため、開発時だけ使ってください。独自の `IMultiProjectionEventStatistics` の実装も再び呼ばれるようになります。キャッチアップは grain のスケジューラーの外から呼ぶことがあるので、スレッドセーフにしてください。渡される `Event` の payload は代わりの値で、意味があるのは `Id`、`EventType`、`SortableUniqueIdValue`、`Tags`、`EventMetadata` だけです。

## 10.25.0 からの更新

- API の変更もデータの移行もありません。パッケージのバージョンを 10.25.1 に更新してください（`DATETIME2` の精度が必要なビューの再構築は上の SQL Server の項、独自の実装は統計の項を参照してください）。依存パッケージのバージョンは 10.25.0 と同じです。
- テンプレートから生成したプロジェクトは、`SekibanDcbTemplateVersion.props` の `SekibanDcbVersion` でライブラリを参照しています。これを `10.25.1` に変えてください。新しく生成するプロジェクトは、10.25.1 のテンプレートのリリース後に 10.25.1 を参照します。
- 同じ修正を 11 系の 11.0.1-preview02 でもリリースする予定です。

## テンプレート

10.25.1 のテンプレートは、ライブラリの後に、別途リリースします。
