# DCB テンプレート 10.23.4

Sekiban DCB 10.23.4 用の 5 つのスターターテンプレートです。生成されるプロジェクトは 10.23.4 のパッケージを参照します。テンプレートのコードは 10.23.3 から変わっていません。

## 含まれるライブラリの変更

生成されるプロジェクトには 10.23.4 のライブラリの変更が入ります。タグの予約中にキャンセルしても予約が残らなくなり、Orleans では予約の呼び出しの失敗が warning としてログに出ます。アップグレード前の確認を含め、詳しくは 10.23.4 のライブラリのリリースノートをご覧ください。

## 生成済みのプロジェクト

テンプレートのパッケージを更新しても、生成済みのプロジェクトは変わりません。変更を取り込むには、`SekibanDcbTemplateVersion.props` の `SekibanDcbVersion` を `10.23.4` に変更してください。
