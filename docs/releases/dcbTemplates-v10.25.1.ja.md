# DCB テンプレート 10.25.1

Sekiban DCB 10.25.1 用の 5 つのスターターテンプレートです。生成されるプロジェクトは 10.25.1 のパッケージと Orleans 10.4.2 を参照し、引き続き net10.0 を対象にします。このノートは、テンプレート 10.25.0 からの変更をまとめたものです。

## 含まれるライブラリの変更

- 10.25.1: Unsafe Window マテリアライズドビューが、null 許容の列が null の行で止まらなくなりました（すべてのテンプレートの天気予報ビューでは、summary のない予報がこれに当たります）。SQL Server では、バイナリ列の null と日付・時刻の値を列の型に合わせてバインドします。PostgreSQL と SQL Server では、safe テーブルから unsafe テーブルへのコピーをデータベースの中で実行します。これにより、PostgreSQL では天気予報ビューの予報日のような `DATE` 列があっても、SQL Server では 1753 年より前の日付があっても、コピーが失敗しなくなりました。DynamoDB のチェックポイントストアは、最初の 1 回だけでなく、すべての条件付きチェックポイント書き込みを保存します（2 つの AWS テンプレートが対象です）。Development 環境では、すべてのテンプレートの `*/event-statistics` ルートが、常に 0 を返すのではなく、再び配信を数えます。Development 以外では、テンプレートは何も記録しない実装を登録するので、ルートは引き続き 0 を返します。公開 API と依存パッケージは 10.25.0 から変わっていません。詳しくは 10.25.1 のライブラリのリリースノートを見てください。

## テンプレートの変更

- テンプレートは Sekiban DCB 10.25.1 を参照します。生成されるプロジェクトのそれ以外の部分は変わっていません。

## 既存のプロジェクト

テンプレートのパッケージを更新しても、すでに生成したプロジェクトは変わりません。ライブラリの変更を取り込むには、`SekibanDcbTemplateVersion.props` の `SekibanDcbVersion` を `10.25.1` にしてください。ほかの変更は要りません。
