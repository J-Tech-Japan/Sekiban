# DCB テンプレート 10.23.1

5 つのスターターテンプレートは公開済みの DCB パッケージを使用し、ローカルでの使いやすさと本番向けの既定動作を改善しました。

- Decider の予約・承認プロジェクターと部屋の状態は、変更する日付インデックスのバケットも含め、入力をコピーして返します。不変なプロジェクション入力を示すため、#997 のスループット最適化を意図的に取りやめました。
- サンプルユーザー、開発用 JWT キー、デバッグ・プロジェクション保守ルート、テストデータ生成、任意オリジンの CORS は Development 限定です。Next.js はサーバー側でサンプル操作の表示を制御し、開発環境以外ではテストデータの手続きを拒否します。Development 以外では JWT キーと必須の Identity 設定を起動時に無条件で検証し、デプロイ時にはシークレットストアから署名キーを供給する必要があります。設定から最初の管理者を作成できます。Identity のスキーマとロールは引き続き全環境で初期化します。
- Blazor のログインページと共有される認証クライアントを削除し、登録・ログインは Next.js に集約しました。API の直接 Cookie 認証は Identity のアプリケーション Cookie を使用し、Bearer 認証も引き続き利用できます。
- マテリアライズドビュー、ストア、Orleans のプロジェクショングレインキー、ライブイベントストリーム、ストレージを扱う 3 つの CLI は、明示的なアプリケーション識別子 (`Sekiban:ServiceId`) を共有します。unsafe-window の読み取りも同じイベントストアを使います。**以前のテンプレートから生成したプロジェクトでは既存の ServiceId を変更しないでください。データは `default` に保存されています。**
- 再試行可能なプロジェクションの追いつき処理・再構築のエラーは、`Retry-After` 付きの 503 を返します。5 つすべてのテンプレートで不正な JSON を 400 として返します。Decider の学生・教室・履修コマンドのドメインルール違反も、ドメインのメッセージ付きの 400 を返します。初回クエリの待機上限など、前提条件のある機能は有効化していません。
- WithoutResult は Azure Queue / Event Hub の設定、永続的な PubSub ストレージ、App Service / Container Apps のサイロエンドポイントに対応します。Dockerfile はインポートするバージョン props を restore 前にコピーし、安定版 .NET イメージと正しいプロジェクト名を使い、最終 .NET コンテナはイメージが提供する非 root ユーザーで、特権の要らないポートを使用します。LocalStack はローカルでトークン不要のイメージに意図的に固定しています。非推奨の OpenAPI 呼び出し、古いコメント、AWS で使えない Cosmos 設定を削除しました。
- 生成ソリューションにローカル実行・本番準備の説明を追加しました。AWS の説明は DynamoDB、list のみの CLI、メモリ上のストリームとグレイン状態、再起動時の制約、RDS のメンバーシップ・リマインダーを正しく記載します。同梱インフラは JWT シークレットを用意しません。

readiness の改善、DynamoDB のテーブル作成競合、実クラウドへのデプロイ検証、複数サイロの検証は今回のテンプレート更新の対象外です。
