# Sekiban DCB 11.0.1-preview01

- バージョン: `11.0.1-preview01`。DCB 11 系の最初のプレビューです。DCB ライブラリは 26 パッケージです。
- 対象は **net10.0 と net11.0** です（net9.0 は対象外になりました。net9.0 では 10.x 系を使ってください）。C# 15 と .NET 11 SDK `11.0.100-rc.3.26522.148` でビルドしています。net10.0 で使う場合、.NET 11 SDK は不要です。
- DCB ライブラリのコードと公開 API は 10.24.0 と同じです。DCB のイベントデータの移行は不要です。

## 依存パッケージ

- **net10.0** の依存バージョンは DCB 10.24.0 と同じです。
- **net11.0** は .NET 11 rc.3 のパッケージを使います。.NET と同じ版で出る `Microsoft.Extensions.*`、Entity Framework Core、`Microsoft.Data.Sqlite` は `11.0.0-rc.3.26522.148`、`Npgsql.EntityFrameworkCore.PostgreSQL` は `11.0.0-rc.3` です。net11.0 の `Npgsql` は 10.0.3 です。
- `Microsoft.Orleans.*` はどちらも 10.4.2 です。Orleans 10.4.2 への更新の注意点は、10.24.0 のリリースノートを参照してください。

## プレビューについて

- net11.0 の依存はリリース候補版です。今後のプレビューで .NET 11 の正式版のパッケージに切り替えます。すべての依存が安定版になったら、正式版 11.0.1 を出します。
- 11 系がプレビューの間も、10.x 系のリリースは続けます。
- このプレビューではテンプレートを出しません。DCB のテンプレートは 10.x 系のままです。
