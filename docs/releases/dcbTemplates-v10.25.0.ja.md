# DCB テンプレート 10.25.0

Sekiban DCB 10.25.0 用の 5 つのスターターテンプレートです。生成されるプロジェクトは 10.25.0 のパッケージと Orleans 10.4.2 を参照し、引き続き net10.0 を対象にします。このノートは、テンプレート 10.24.3 からの変更をまとめたものです。

## 含まれるライブラリの変更

- 10.25.0: ライブラリのパッケージは net10.0 と net11.0 を対象にし、net9.0 向けのアセットを含まなくなりました。net10.0 と net11.0 のアセットは、10.24.3 と同じバージョンの依存パッケージを使います。公開 API と動作は 10.24.3 から変わっていません。詳しくは 10.25.0 のライブラリのリリースノートを見てください。

## テンプレートの変更

- テンプレートは Sekiban DCB 10.25.0 を参照します。生成されるプロジェクトは引き続き net10.0 を対象にし、それ以外の部分も変わっていません。

## 既存のプロジェクト

テンプレートのパッケージを更新しても、すでに生成したプロジェクトは変わりません。ライブラリの変更を取り込むには、`SekibanDcbTemplateVersion.props` の `SekibanDcbVersion` を `10.25.0` にしてください。net10.0 を対象にしたプロジェクトなら、ほかの変更は要りません。
