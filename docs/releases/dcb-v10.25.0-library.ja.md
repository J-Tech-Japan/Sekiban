# Sekiban DCB 10.25.0

- バージョン: `10.25.0`。DCB ライブラリは 26 パッケージです。net10.0 と net11.0 を対象とします。
- .NET 9 の対応を外しました。パッケージに net9.0 のアセットは入っていません。.NET 9 は 2026 年 11 月にサポートが終了しています。net9.0 を対象にしているプロジェクトは 10.24.x を使い続けてください。
- パッケージに net11.0 のアセットを追加しました。net10.0 と net11.0 のアセットは、10.24.3 と同じバージョンの依存パッケージを使います（EF Core・Npgsql・Microsoft.Extensions は 10.x、Orleans は 10.4.2）。.NET 11 のパッケージは要りません。
- 公開 API と動作は 10.24.3 から変わっていません。DCB のイベントデータの移行は不要です。

## テンプレート

10.25.0 のテンプレートは、ライブラリの後に、別途リリースします。生成されるプロジェクトは引き続き net10.0 を対象とします。
