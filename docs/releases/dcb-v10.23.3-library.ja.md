# Sekiban DCB 10.23.3

- バージョン: `10.23.3`。DCB ライブラリは 26 パッケージです。net9.0 と net10.0 を対象とし、`Microsoft.Orleans.*` は 10.3.1 のままです。
- データやスキーマの移行は不要で、公開 API の変更もありません。

## 修正

- **Orleans の materialized view が、catch-up の途中まで進んだときも、stream からの通知を保持するようになりました**（issue #1339）。catch-up のバッチがいくつかのイベントを適用したものの、stream が知らせた最新のイベントの手前で止まった場合（バッチサイズによる場合など）、`MaterializedViewGrain` はその通知を捨てていました。そのため、次の読み取りでまだ適用できるイベントがないと、catch-up が終了していました。知らされたイベントが次に読まれるのは、別の通知か `RefreshAsync` が来たとき、またはイベントストアを定期的に読み直す処理によってでした。この処理は、最後の catch-up の試行から `max(PollInterval, SafeWindowMs)` の後（既定の設定では 5 秒後）に実行できるようになります。イベントが失われることはありませんでした。今回から、適用した位置がその通知に追い付くまで、grain は通知を保持します。

## アップグレード前の確認

- そのような通知が残っている間に、catch-up の読み取りが進まなかった場合、`RefreshAsync` の再試行の間隔は、10 ms ではなく `PollInterval` になります。これまでどおり、上限（`CatchUpStallThreshold`）に達すると待つのをやめます。
- 途中まで進んだ後、知らされたイベントがいつまでも読めない場合、`CatchUpStallThreshold` の後に catch-up を停止し、その通知を grain の状態のエラーとして報告するようになりました。読み取りで何も適用されなかった場合は、10.23.2 でもすでにそうなっていました。
